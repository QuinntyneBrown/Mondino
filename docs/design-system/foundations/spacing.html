Spacing

One 4 px scale for every gap and every padding, and the sizes a few components own.

Status: stableSince v1.0
  • Overview
  • The scale
  • Usage
  • Component sizes
  • Tokens

Overview

Space is what groups things. Related things sit close; unrelated things sit apart. Every distance comes from the scale below, so the same decision is made the same way on every screen.

Usage

WhereTokenExample
Icon to its label--space-1-5 to --space-2A button’s icon, a kind and its icon
Inside a chip, a pill, a label--space-2 to --space-3Pin label, moment pill
Between rows in a list--space-2 of padding eachPanel rows
Inside a card or the panel--space-5, then --space-6 from 576 pxPanel, invite card
Between a form’s fields--space-5Join
Between blocks in a panel--space-6 to --space-8Teammate panel
Between sections of a page--space-10 to --space-12Team: ribbon, then the list
Page edge to content--layout-margin16 px, 24 px from 576 px
  • Inside a component use --space-6 or less; between components use --space-6 or more.
  • Space does not scale with the width of the screen. A breakpoint changes the token.
