Foundation

Layout

Five screens, each one column on a phone and using the width it is given on a tablet and a desktop.

Status: stableSince v1.0
  • Overview
  • Breakpoints
  • Grid
  • Page templates
  • Usage
  • Tokens

Overview

Mondino is built phone first. Every screen works from 320 px wide and never scrolls sideways. As the width grows the globe grows; text keeps a readable measure.

Breakpoints

WidthTokenWhat changes
under 576 pxbaseOne column. The header shows the mark without the wordmark. The heading is above the globe and the panel under it. Dialogs are sheets from the bottom.
576 px--layout-breakpoint-smWordmark in the header. Heading and legend lie over the globe’s corners. Country and postal code share a row. Dialogs are centred.
768 px--layout-breakpoint-mdTeam is a table with all its columns. “Invite teammate” appears.
992 px--layout-breakpoint-lgThe panel sits to the right of the globe; the Join form beside the globe; the pin card beside the settings.
1200 px--layout-breakpoint-xlText columns stay capped and centred; the globe keeps growing.

A media query cannot read a custom property, so the values are repeated in components.css as 36rem, 48rem, 62rem and 75rem. Queries are min-width, in rem.

Grid

Columns, gutter and margin are tokens that change with the width: 4 columns under 768 px, 8 from 768 px, 12 from 992 px. Resize the window to see them change.

Usage

  • The header is --layout-header-height tall at every width.
  • From 992 px the Globe screen is exactly the height of the window: the globe stays in view while the panel scrolls.
  • Use 100dvh, not 100vh, so a phone’s browser bars do not clip the screen.
  • Nothing is cut off and nothing overlaps at 320, 375, 576, 768, 992, 1200 and 1920 px.
