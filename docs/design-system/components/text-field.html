Text field

One line of text a teammate types: their name, their postal code, a work email, a city, or a search.

Overview

Mondino’s text fields are “Your name” and “Postal code” on Join, Create Team and Profile & Settings; “Team name” on Create Team; “Work email” on Sign In and Create Team; “Your city”, which takes the postal code’s place on Join while the lookup is down; and the search above a large team. A text field sits in a form field, which gives it its label and its message; the search alone is labelled by its name and placeholder.

Anatomy

Its parts, in reading order:

  1. LabelAbove the input, always visible
  2. Value16 px body text; tabular figures for a postal code
  3. Container52 px tall, 12 px radius, a 3:1 edge

Responsive behaviour

The field takes the full width of its column. The font stays 16 px so a phone does not zoom on focus.

Theming

It reads semantic tokens only, so light and dark both come from tokens.css. To re-theme it, override the tokens listed under Tokens at :root or in a [data-theme] block; never write a colour in the component.

Accessibility

Role and pattern

A native <input> with a <label for>: type="text", type="email" for a work email, type="search" for the search. “Your city” is a WAI-ARIA combobox with a list of the chosen country’s cities.

Keyboard

KeyAction
TabMoves into and out of the field. On Join and Create Team, leaving the postal code starts its lookup; on Profile & Settings “Look up” starts it
↓ / ↑ / EnterIn “Your city”: moves through the cities and chooses one
EscIn the search: clears it

Focus

The edge turns to --color-focus-ring and doubles to 2 px. Nothing else moves.

Labelling

The label is always visible; a form’s field has no placeholder. The search is the one exception: it has no visible label, so its placeholder and its accessible name are both “Find a person or city”. A message is tied to the input with aria-describedby, and an invalid input carries aria-invalid="true".

Contrast

Typed text --color-fg-default on --color-bg-surface
Edge --color-border-strong on --color-bg-surface
Invalid edge --color-danger-border on --color-bg-surface

Motion

Colour and size changes take --duration-fast. Reduced motion sets every duration token to nothing, so the change is instant with no extra rule.

Touch

The target is at least 44 × 44 px (--target-comfortable).

Content

Labels are nouns in sentence case: “Your name”, “Postal code”, “Team name”, “Work email”, “Your city”. A name, and what is typed in “Your city”, is at most 60 characters and a postal code 12; the field says so only when the limit is passed.
