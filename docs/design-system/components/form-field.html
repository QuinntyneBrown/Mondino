Form field

The wrapper every input sits in: its label above, its message below.

Overview

A form field stacks a label, a control and, when there is one, a line of help or an error. A field row puts two short fields side by side, and on Profile & Settings ends in a button, “Look up”, that starts the postal code lookup. See the forms pattern for when a form validates and how it reports.

Anatomy

Its parts, in reading order:

  1. Label14 px medium, 6 px above the control
  2. ControlA text field or a select
  3. Help (optional)One quiet line, 6 px below
  4. Error (when invalid)An icon and what to fix, 6 px below

Responsive behaviour

One column under 576 px. From 576 px a field row is two columns: the first takes the room, the second is --layout-field-short wide. A field row with an action stacks the button under the two fields under 576 px, at its own width; from 576 px the button is a third column, as tall as the inputs and level with them.

Theming

It reads semantic tokens only, so light and dark both come from tokens.css. To re-theme it, override the tokens listed under Tokens at :root or in a [data-theme] block; never write a colour in the component.

Accessibility

Role and pattern

A <label for> and a native control. Help and errors are paragraphs the control points at with aria-describedby; an error that appears while typing is role="alert". “Look up” is a type="button" and never submits the form.

Keyboard

The wrapper takes no keys; its control does. In a field row with an action, Tab goes country, postal code, “Look up”.

Focus

On submit with errors, focus moves to the form’s summary; each of its links moves focus to a field.

Labelling

An error names the field’s problem and how to fix it, with an icon as well as colour.

Contrast

Label --color-fg-default on --color-bg-canvas
Error --color-danger-fg on --color-bg-canvas

Motion

Colour and size changes take --duration-fast. Reduced motion sets every duration token to nothing, so the change is instant with no extra rule.

Touch

Tapping a label focuses its control.

Content

An error starts with what to do: “Add your name so teammates know whose pin this is.”, “Enter a postal code.”, “Give your team a name — teammates see it when they join.” It never says “invalid” or “required” alone. Help says what the field is for: “We’ll send sign-in links here.”
