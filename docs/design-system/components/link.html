Link

A link goes somewhere: to Moments, to Profile & Settings, back to the globe.

Overview

Use a link for navigation. Inline links are underlined and pin-coloured: “Sign in” and “Start a team” under a form, “Choose moments” in the panel’s note. “All moments” and “2 more on the Team page” in the panel are standalone links with a trailing arrow. A whole row that opens a teammate is a panel row, not a link in text.

Responsive behaviour

A standalone link is at least 44 px tall at every width. An inline link wraps with its sentence.

Theming

It reads semantic tokens only, so light and dark both come from tokens.css. To re-theme it, override the tokens listed under Tokens at :root or in a [data-theme] block; never write a colour in the component.

Accessibility

Role and pattern

A native <a href>. Mondino opens nothing in a new tab.

Keyboard

KeyAction
EnterFollows the link
TabMoves to the next control

Focus

The shared 2 px focus ring.

Labelling

The link’s text says where it goes, on its own, out of context. Never “click here”.

Contrast

Link on the page --color-fg-link on --color-bg-canvas
Link on a surface --color-fg-link on --color-bg-surface

Motion

Colour and size changes take --duration-fast. Reduced motion sets every duration token to nothing, so the change is instant with no extra rule.

Touch

A standalone link has a 44 px tall target. An inline link takes the height of its line.

Content

Name the destination: “All moments”, “Sign in”, “Start a team”, “Choose moments”, “Back to the globe”. Sentence case, no full stop. A link in a note is at least 44 px tall.
