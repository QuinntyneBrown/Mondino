Spinner

A turning ring that says one action is in flight.

Overview

A spinner sits inside the thing that is busy: a button being pressed, the lookup message while a postal code is found, the save bar while saving. It never stands alone on a screen; a screen that is loading uses skeletons.

Anatomy

Its parts, in reading order:

  1. RingThe loader icon, turning
  2. WordsWhat is happening, always beside it

States

A spinner turns or is absent.

Responsive behaviour

The same at every width.

Theming

It reads semantic tokens only, so light and dark both come from tokens.css. To re-theme it, override the tokens listed under Tokens at :root or in a [data-theme] block; never write a colour in the component.

Accessibility

Role and pattern

Decorative: aria-hidden="true". The words beside it, or the button’s aria-busy, carry the state.

Keyboard

It is not focusable and takes no keys; it is read in place by a screen reader.

Focus

Not focusable.

Labelling

Never without words.

Contrast

Ring in a message --color-fg-muted on --color-bg-canvas

Motion

One turn every --duration-deliberate. Under reduced motion it stands still and the words carry the state.

Touch

Not a control.

Content

The words are the action in progress, ending in an ellipsis: “Finding 20121…”, “Placing your pin…”, “Saving…”.
