Segmented control

One pill holding a few options, exactly one of them chosen: the header’s tabs, the Team filter, a two-way setting.

WCAG 2.2 AAStatus: stableSince v1.0

Overview

Use it for two to four choices that are all visible and exactly one of which holds. It has three jobs, with the same look and a different role each: the primary navigation (links, aria-current), the Team filter (tabs, aria-selected) and a setting such as °C or °F (radios, aria-checked).

For several independent on-or-off filters use chips. For one on-or-off setting use a switch.

Anatomy

Its parts, in reading order:

  1. Chosen optionInk fill, paper text
  2. Count (optional)Tabular figures, regular weight, the option’s own colour
  3. OptionMuted text; ink on hover
  4. TrackA surface pill with a hairline

Responsive behaviour

It never wraps to two rows. Under 576 px the options tighten to 12 px of padding, and under 360 px the header’s tabs tighten to 8 px so mark, tabs and avatar fit 320 px. Each option keeps a 44 px tall target while the pill is drawn 36 px.

Theming

It reads semantic tokens only, so light and dark both come from tokens.css. To re-theme it, override the tokens listed under Tokens at :root or in a [data-theme] block; never write a colour in the component.

Accessibility

Role and pattern

Navigation: a <nav aria-label="Primary"> of links, the current one with aria-current="page". Filter: WAI-ARIA Tabs (tablist, tab, tabpanel), activated as focus moves. Setting: WAI-ARIA Radio Group.

Keyboard

KeyAction
TabNavigation: each link in turn. Filter and setting: into the group, on its chosen option
← / →Filter and setting: move to the neighbouring option and choose it
Home / EndFilter and setting: first and last option
EnterNavigation: follows the link

Focus

The shared ring around the option. In a filter or a setting only the chosen option is in the tab order.

Labelling

The group has a name (“Primary”, “Filter by status”, “Clock”). A count is part of the option’s name: “Working now 8”.

Contrast

Chosen option --color-fg-on-accent on --color-accent
Other options --color-fg-muted on --color-bg-surface

Motion

Colour and size changes take --duration-fast. Reduced motion sets every duration token to nothing, so the change is instant with no extra rule.

Touch

The target is at least 44 × 44 px (--target-comfortable).

Content

One or two words per option. Counts follow the label with a space. Keep the order fixed; never sort options by count.

Class / attributeEffect
.segmentedThe track. Give it the role and the name of its job.
.segmented__optionAn option: a link, a tab or a radio.
aria-current="page"The current screen (navigation).
aria-selected="true"The chosen filter (tabs).
aria-checked="true"The chosen setting (radios).
.segmented__countA count after the label.
.segmented__checkThe tick shown on a chosen radio.
