Overview

Mondino has one select, “Country”, listing the supported countries in alphabetical order. It is the browser’s own select, so on a phone it opens the system picker.

Anatomy

Its parts, in reading order:

  1. LabelAbove the control
  2. Chosen value16 px body text
  3. Chevron16 px, muted, decorative

Variants

There is one variant: the native select.

Sizes

It has one size.

States

VariantDefaultFocusInvalidDisabled
Select

Responsive behaviour

Full width under 576 px, above the postal code. From 576 px it shares a row with the postal code and takes the room the postal code leaves.

Theming

It reads semantic tokens only, so light and dark both come from tokens.css. To re-theme it, override the tokens listed under Tokens at :root or in a [data-theme] block; never write a colour in the component.

Accessibility

Role and pattern

A native <select> with a <label for>.

Keyboard

KeyAction
↑ / ↓Changes the country
Enter / SpaceOpens the list
A letterJumps to the first country that starts with it

Focus

The same focus edge as a text field.

Labelling

The label “Country”. Changing the country clears a found city and its pin, and the lookup runs again.

Contrast

Value --color-fg-default on --color-bg-surface
Edge --color-border-strong on --color-bg-surface

Motion

Colour and size changes take --duration-fast. Reduced motion sets every duration token to nothing, so the change is instant with no extra rule.

Touch

The target is at least 44 × 44 px (--target-comfortable).

Content

Countries are named in English and sorted alphabetically. No “Select a country” entry: the list starts on a real country.
