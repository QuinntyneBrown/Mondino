Team table

Everyone, west to east: each teammate’s location, local time, offset from you, weather and next moment.

Overview

The table on the Team screen lists every teammate ordered by their time zone’s current offset from UTC, then by longitude. A row opens the Globe with that teammate’s pin selected. It is filtered by a segmented control: All, Working now, Asleep.

Anatomy

Its parts, in reading order:

  1. AvatarDecorative
  2. NameThe row’s link; “(you)” on your own
  3. StatusIn words, under the name
  4. City and countryNever a postal code
  5. Local timeGabarito, tabular, with a status dot
  6. Offset“7 h behind”; a dash for you
  7. Weather and next momentIcon and degrees; a moment pill or a dash

Responsive behaviour

Under 768 px it is not a grid of columns: each teammate is a block with the name and status at the left, the local time with city and offset at the right, and the next moment on a line beneath. From 768 px it is a table with all six columns, and between 768 and 992 px the columns tighten and a moment pill may wrap. From 992 px a chevron ends each row. For a large team the rows held in the page stay bounded.

Theming

It reads semantic tokens only, so light and dark both come from tokens.css. To re-theme it, override the tokens listed under Tokens at :root or in a [data-theme] block; never write a colour in the component.

Accessibility

Role and pattern

A real <table> with a hidden caption, column headers with scope="col", and the name as each row’s header. The name is the row’s one link; its target covers the row.

Keyboard

KeyAction
TabMoves row to row, by name
EnterOpens the Globe with that teammate’s pin selected

Focus

The ring is drawn around the whole row.

Labelling

Status is given in words. A weather icon carries the condition as its label. A dash has a label: “You”, “Nothing coming up”.

Contrast

Name --color-fg-default on --color-bg-canvas
Status and offset --color-fg-muted on --color-bg-canvas
Row hover --color-fg-default on --color-bg-surface

Motion

Colour and size changes take --duration-fast. Reduced motion sets every duration token to nothing, so the change is instant with no extra rule.

Touch

The whole row is the target.

Content

Column headers: “Person”, “Location”, “Local time”, “vs you”, “Weather”, “Coming up”. A name is data: it is shown as the characters that were typed, never as markup.
