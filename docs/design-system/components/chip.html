Chip

A filter that is pressed or not: the kinds of moment.

Overview

Chips filter the Moments list by kind. Exactly one is pressed, “Everything” to begin with. Each kind’s chip carries that kind’s icon and its name.

Anatomy

Its parts, in reading order:

  1. Kind icon14 px; absent on “Everything”
  2. LabelThe kind’s name
  3. ContainerA pill, 36 px drawn, 44 px target

Sizes

It has one size.

States

VariantDefaultHoverFocusPressed
Chip

Responsive behaviour

Chips wrap onto as many rows as they need, 8 px apart. They never scroll sideways.

Theming

It reads semantic tokens only, so light and dark both come from tokens.css. To re-theme it, override the tokens listed under Tokens at :root or in a [data-theme] block; never write a colour in the component.

Accessibility

Role and pattern

A <button aria-pressed> inside a named role="group".

Keyboard

KeyAction
TabMoves from chip to chip
Enter / SpacePresses the chip and releases the one that was pressed

Focus

The shared ring.

Labelling

The kind’s name; the icon is decorative. The pressed state is exposed through aria-pressed and shown by an ink fill, never by colour alone.

Contrast

Pressed --color-fg-on-accent on --color-accent
Not pressed --color-fg-default on --color-bg-surface
Edge --color-border-strong on --color-bg-surface

Motion

Colour and size changes take --duration-fast. Reduced motion sets every duration token to nothing, so the change is instant with no extra rule.

Touch

The target is at least 44 × 44 px (--target-comfortable).

Content

The four kinds are named exactly “Holiday”, “Formula 1”, “Local event” and “Sport”. The first chip is “Everything”.
