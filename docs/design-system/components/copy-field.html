Copy field

A read-only link with a button that copies it: the team’s invite link, in the invite dialog and on Create Team.

Overview

A copy field shows a link that is meant to be passed on, with the button that copies it. Mondino has one such link, the team’s invite link, and shows it this way in two places: the invite dialog and Create Team once the team is made. The link is in a read-only input, so it can be selected and copied by hand when the browser will not copy it for the teammate.

The invite card on the Globe of a team of one shows the same link as plain text with “Copy” beside it; that is part of the card.

Anatomy

Its parts, in reading order:

  1. LabelVisible above it (“Invite link”), or an aria-label where a heading already says it
  2. ValueThe link, read-only, on one line; it ends in an ellipsis when it is too long
  3. CopyA small primary button with an icon: “Copy link”
  4. WellA 3:1 edge and a 16 px radius around both

Sizes

It has one size: the value is 44 px tall and the button is the small button.

States

Copying succeeds: the link is on the clipboard and a toast says so; in the invite dialog the dialog closes, and on Create Team “Copy link” reads “Copied” with a tick. Copying is refused: the field stays, the link is selected and focused so one keystroke copies it, and a toast that stays says which keys to press.

VariantDefaultCopying was refused: the link selected and focused
Copy field

Responsive behaviour

It takes the full width of its container at every width. The value takes the room the button leaves and never wraps; the button never shrinks. In the invite dialog under 576 px, where the dialog is a sheet, it is the width of the sheet.

Theming

It reads semantic tokens only, so light and dark both come from tokens.css. To re-theme it, override the tokens listed under Tokens at :root or in a [data-theme] block; never write a colour in the component.

Accessibility

Role and pattern

A native <input type="text" readonly> beside a native <button>. Read-only, not disabled: a disabled input cannot be focused or selected.

Keyboard

KeyAction
TabThe link, then “Copy link”
Enter / SpaceOn the button, copies the link
Ctrl + C / ⌘ + CWith the link selected, copies it by hand

Focus

The value takes the shared focus ring inside the well. In the invite dialog focus starts on “Copy link”. When copying is refused, focus moves to the value with all of it selected.

Labelling

The value is named: by a visible <label> (“Invite link”) in the dialog, by aria-label="Invite link" on Create Team. The button’s label is its name; its icon is decorative. The result of copying is announced by the toast, not by the button alone.

Contrast

Link on the canvas --color-fg-default on --color-bg-canvas
Link on a surface --color-fg-default on --color-bg-surface
Edge --color-border-strong on --color-bg-canvas
Button --color-fg-on-accent on --color-accent

Motion

None of its own.

Touch

The value is 44 px tall. The button is the small button; the well’s padding brings its target to 44 px.

Content

The link is shown without its scheme, as it would be read aloud: “mondino.app/join/northwind-7Kq2”. The label is “Invite link” and the button is “Copy link”; once copied on Create Team it reads “Copied”. A postal code, an email or anything else private is never put in a copy field.
