Skip link

The first thing Tab reaches on every screen: a link straight to the content.

Overview

It is hidden until it has keyboard focus, then appears at the top left over the header. It lets a keyboard user pass the header’s tabs on every screen.

Anatomy

Its parts, in reading order:

  1. Label“Skip to content”, on an ink pill

Responsive behaviour

The same at every width.

Theming

It reads semantic tokens only, so light and dark both come from tokens.css. To re-theme it, override the tokens listed under Tokens at :root or in a [data-theme] block; never write a colour in the component.

Accessibility

Role and pattern

A link to #main, the first focusable element in the page.

Keyboard

KeyAction
TabReveals it, as the first stop
EnterMoves focus to the main content

Focus

Visible only while focused, with the shared ring.

Labelling

“Skip to content”.

Contrast

Label --color-fg-on-accent on --color-accent

Motion

Colour and size changes take --duration-fast. Reduced motion sets every duration token to nothing, so the change is instant with no extra rule.

Touch

The target is at least 44 × 44 px (--target-comfortable).

Content

Always “Skip to content”.
